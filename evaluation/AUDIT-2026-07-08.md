## 2. Ràng buộc integrity được giữ nguyên sau sửa

- Sweep/hook/task chỉ **đọc** state file, ghi vào `.rca/eval/` — không chạm
  bài đo (IN-3).
- Judge trên Gauss bắt buộc phiên ClineSR **mới** (`judge-pending`), giữ
  cách ly IN-4; điểm sai dimension/thang vẫn bị `validate_scores` loại (V8).
- Ngưỡng gate + trọng số RQS nằm trong code + criteria doc, đổi = PR review
  (IN-8); provenance < 100% cap RQS ≤ 49 (IN-9).
- Record/scores/coverage là 3 loại file duy nhất rời máy — vẫn ẩn danh,
  không log thô (FR-2).

## 3. Việc còn lại (ngoài phạm vi đợt này)

1. Xác nhận tên sự kiện hook trên bản ClineSR nội bộ (Settings → Features →
   Hooks) và gắn `rca_eval_hook.py`; nếu build không có Hooks, tầng 3+4 đã
   đủ đảm bảo coverage.
2. Điền endpoint Gauss gateway thật vào `RCA_JUDGE_API_URL` (nếu có) — hiện
   fleet chạy được ngay bằng agent-as-judge.
3. Dựng golden set ≥ 20 case và chạy baseline agent-vs-manual (framework §3).
4. Hiệu chuẩn judge Gauss vs human trên ≥ 10 run (Spearman ≥ 0.6, IN-5)
   trước khi tính điểm judge vào gate chính thức.
