Design Document: 3GPP FTA Seed-Init Bypass (v6.1)

1. Objective

The 3gpp-fta-seed-init skill is designed to create a Fast-Track for the 3GPP UE RCA v6 system. Instead of forcing the system to run through the time-consuming Phase 1 (Scoping) and Phase 2 (Timeline generation) for already well-understood failures, engineers can directly initialize the RCA State File from a specific failure event and jump straight into Phase 3 (Fault Tree Analysis).

2. Reason for Change / The Problem

The initial draft design of 3gpp-fta-seed-init contained a critical architectural flaw:
  • It only required the engineer to provide the top_event and completely skipped the creation of the phase1_scope_filter data block.
  • The absence of phase1_scope_filter (specifically the lack of procedure and rat) forced the system to set the spec_anchored = false flag at the entry of Phase 3.
  • Consequently, Phase 3.1 could not look up 3GPP specifications using the spec_query skeleton tool. Instead, it fell back into a pure LLM prediction mechanism (hallucination-prone hypothesis generation). This violated the core "Spec-Anchored" principle of v6.

3. What Changed

To resolve the above flaw and create a "Perfect Bypass", the current design implements the following changes:

  1. Stricter Input Requirements: The engineer is strictly required to provide 4 parameters: top_event, scope_window, procedure, and rat.
  2. State Injection: The skill automatically synthesizes these 4 parameters and "injects" a valid phase1_scope_filter block into the State File.
  3. Spec-Anchored Activation: The skill forces the spec_anchored = true flag on the root event, ensuring that Phase 3.1 always uses 3GPP specs.
  4. Review Feature Addition (UX Upgrade): After generating the State File, the draft file is presented so the engineer can review and edit it directly (Interactive Editing) before finalizing the execution flow.

4. How it Changed

The overall architecture of v6 remains unbroken thanks to the application of the Additive-Only (Open-Closed Principle):

  • Completely Decoupled: The 3gpp-fta-seed-init skill does not call any other skills; it acts solely as a State-file generator.
  • Dispatcher Update (rca.md): The main workflow was appended with a new Case: phase2_confirmed_via_seed branch. Normal runs are completely unaffected.
  • Audit Preservation (keyword-provenance-rules.md): Added a single exception (carve-out) only for data tagged with ENGINEER_PROVIDED. All subsequent AI-generated deductions in Phase 3 must still undergo strict Auditing.
  • Orchestrator Bypass (3gpp-rca-orchestrator): Added the conditional statement if meta.mode != "seed_and_run" to skip the phase2_ecf check for the bypass branch, while maintaining strict checks for the standard branch.
